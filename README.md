# Labrab
Саяпин Сергей Ки25-21б Вариант 16
нужно сделать простого сапёра: есть поле с клетками, под некоторыми спрятаны мины. Игрок открывает клетки и старается не подорваться. Значит надо хранить три вещи про каждую клетку: что там лежит, мина или число мин рядом, открыта ли она и стоит ли на ней флажок, можно создать для этого три массива. Сначала расставить мины случайно и посчитать для каждой клетки, сколько мин вокруг. Потом сделать цикл: создать поле, считать ход игрока допустим r 3 5 или f 3 5, проверить ввод. Если игрок открыл пустую клетку,то она сама открывает соседей пока не упрётся в цифры. После каждого хода проверить, если закрытых клеток осталось ровно столько, сколько мин, то победа. Подорвался на мине проигрыш. Когда игра кончилась, показывать всё поле и результат. Всё разбито на маленькие методы: создать поле, открыть клетку, проверить победу, нарисовать.
